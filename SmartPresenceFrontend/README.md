# SmartPresence Frontend

Portail Angular 20 réservé à l'administration. Il utilise les routes API Spring Boot sous `/api` et l'authentification JWT.

## Démarrer

1. Installer Node.js 20.19+.
2. Dans ce dossier : `npm install` puis `npm start`.
3. Démarrer le backend sur `http://localhost:8080`.

Les pages de ressources partagent le même tableau responsive (recherche, tri/pagination client, exports prêts à relier) et sont chargées à la demande.
